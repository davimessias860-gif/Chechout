PROTEÇÕES E COMPORTAMENTO
Sem chave, ID correto de João Victor ou confirmação do principal, o backend bloqueia a criação. Quando liberado, consulta ambos os recebedores; rejeição, ID divergente, inatividade ou falha de consulta impedem o POST do pedido. A API de criação precisa aceitar Pix com split na modalidade contratada. Contas PSP podem exigir endereço do comprador; o formulário de seis campos não inventa dados para contornar exigências.

Pix Copia e Cola e QR Code usam exclusivamente o conteúdo devolvido pela Pagar.me. O QR Code é renderizado localmente, sem serviços externos de imagem. Os dados pessoais são usados no servidor para a cobrança. A consulta automática de status ocorre a cada 12 segundos com a página visível, por até 30 minutos, e também está disponível por botão. Ela usa a API real e cookie de sessão HttpOnly, Secure e SameSite. A sessão corresponde à última cobrança gerada no navegador. Não há geração simulada em produção.

O valor de expiração solicitado é 30 minutos. Repetições com os mesmos dados e a mesma página reutilizam a chave de idempotência. Não recarregue a página para repetir uma cobrança de resultado incerto; confira antes o painel da operadora.
